# Посмотри в окно

Учебный проект Яндекс Практикума: страница с видео из окон городов. Слева видеоплеер и форма поиска по городу и времени суток, справа список найденных видео.

## Репозиторий

https://github.com/kirillbukin567-art/posmotri-v-okno-ad

## Что реализовано

- Раскладка на flex: две колонки, форма в одну строку, список с прокруткой.
- Размеры и подгонка изображений и видео через `object-fit` и `object-position`.
- Типографика: шрифты Oswald и Fira Sans Condensed, обрезка длинных названий («…») и описаний (`line-clamp`).
- Кастомные чекбоксы на псевдоэлементах, скрытие настоящих через `.visually-hidden`.
- Состояния `:hover`, `:active`, `:focus-visible` для кнопок, чекбоксов, поля ввода и карточек.
- Контекст позиционирования для прелоадеров и блока ошибки.

## Технологии

- HTML5, CSS3 (flex, псевдоэлементы, `:has()`, `:focus-visible`)
- Методология БЭМ для именования классов
- Автотесты Яндекс Практикума (GitHub Actions)
